Sakai Tasks MCP

大学の Sakai LMS と AI をつなぐ MCP サーバ

Windows インストール macOS インストール GitHub →

概要

Sakai Tasks MCP は、大学で利用されている Sakai LMS（名古屋大学、京都大学、東京農工大学、東京都立大学など）から、通知や課題の締め切り、講義資料などを取得し、Claude Desktop、Cursor、Antigravity などの AI アシスタントと連携するための MCP (Model Context Protocol) サーバーです。

「今週の課題の締切は？」「重要なお知らせはある？」「講義資料をダウンロードして」と AI に話しかけたら Sakai 上の情報を取得できるようにします。

機能

課題やお知らせ、カレンダーなど講義の状況を取得

課題や小テストの締切、講義からのお知らせ、カレンダーの予定など、講義の状況をまとめて確認できます。

資料のダウンロード

講義で配布された資料や課題の添付ファイルを、指定したフォルダに保存できます。

講義ごとの公開範囲設定

AI がアクセスできる情報の範囲を、講義ごとに 4 段階（全て・強・弱・無効）で細かく設定できます。

ログイン管理

セッションをローカルに暗号化保存し、ログイン操作を最低限にします。ログイン操作が必要なときは自動で大学のログイン画面が表示されます。

MCP ツール一覧
ツール名 説明
get_upcoming_deadlines 締切がある課題・小テストを取得し、期限順に整理して返します。
get_course_dashboard 指定した講義の状況（課題、小テスト、直近のお知らせ、授業資料）を取得します。
get_announcements 通知を取得します。
get_assignments 課題の一覧または詳細（提出期限、指示文、添付資料など）を取得します。
get_quizzes 小テスト・オンラインクイズの一覧や締切情報を取得します。
get_calendar_events カレンダーに登録されたスケジュールやイベント予定を取得します。
get_course_materials 講義の配布資料リンク・フォルダ一覧を取得します。
download_material 講義資料や添付ファイルを指定のローカルフォルダにダウンロードします。
get_unread_messages_and_forums 講義内の個人宛メッセージや掲示板（フォーラム）の未読件数と直通リンクを取得します。
list_courses 所属している講義一覧と講義IDを取得します。
open_settings 大学ドメインの変更や講義ごとの情報開示ポリシーなどを設定する GUI 画面を起動します。
get_settings 現在の設定（ドメイン、講義別 AI 利用ポリシー等）を取得します。
check_auth_status 大学ポータルのログインセッションが有効かどうかを確認します。

Windows インストール

Windows 版 圧縮ファイルをダウンロード

セットアップ手順

  1. ダウンロードした ZIP ファイルを任意のフォルダ（例: C:\tools など）に解凍します。
  2. 解凍先フォルダ内の run.bat の絶対パスを確認します。

    パスの確認方法: エクスプローラーで解凍先フォルダを開き、run.bat を 右クリック して「パスのコピー」を選択すると、クリップボードに絶対パスがコピーされます。

  3. AI アシスタントの MCP 設定に登録します。

    設定ファイルの場所:

    • Claude Desktop: %APPDATA%\Claude\claude_desktop_config.json
    • Cursor: %USERPROFILE%\.cursor\mcp.json（全体）／ ワークスペース直下の .cursor\mcp.json（プロジェクト単位）
    • Google Antigravity: %USERPROFILE%\.gemini\config\mcp_config.json

    設定 JSON の例:

    {
  "mcpServers": {
    "sakai-tasks": {
      "command": "cmd.exe",
      "args": [
        "/c",
        "<あなたが解凍したrun.batファイルのパス>"
      ]
    }
  }
}

    ※ JSON 内ではパスのバックスラッシュ（\）を \\ にエスケープしてください（例: C:\\tools\\sakai-tasks-mcp-windows\\run.bat）。

    AI に設定ファイルへの追記を依頼する場合のプロンプト例:

    あなたのMCP設定ファイルに、以下のMCPサーバーを追加してください。
名前: sakai-tasks
コマンド: cmd.exe
引数: ["/c", "<あなたが解凍したrun.batファイルのパス>"]
  4. AI アシスタントを再起動します。
  5. AI のチャット欄で「初期設定を開いて」と指示します。
  6. 設定画面が開いたら、所属大学のドメイン（例: tact.ac.thers.ac.jp や lms.gakusei.kyoto-u.ac.jp 等）を入力または一覧から選択します。設定は自動保存されるため、右上の閉じるボタン（✕）で画面を閉じます。
  7. AI のチャット欄で「直近の課題を教えて」など Sakai に関する質問をすると、ログイン画面が自動で開きます。ログインが完了すると画面が自動で閉じ、AI が情報を回答します。

macOS インストール

macOS 版 圧縮ファイルをダウンロード

セットアップ手順

  1. ダウンロードしたアーカイブ（.tar.gz）を任意のフォルダ（例: /Users/username/tools や ~/tools など）に展開（解凍）します。
  2. 解凍先フォルダ内の run.sh の絶対パスを確認します。

    パスの確認方法: Finder で解凍先フォルダを開き、run.sh を 右クリック して「パス名をコピー」を選択します。

  3. AI アシスタントの MCP 設定に登録します。

    設定ファイルの場所:

    • Claude Desktop: ~/Library/Application Support/Claude/claude_desktop_config.json
    • Cursor: ~/.cursor/mcp.json（全体）／ ワークスペース直下の .cursor/mcp.json（プロジェクト単位）
    • Google Antigravity: ~/.gemini/config/mcp_config.json

    設定 JSON の例:

    {
  "mcpServers": {
    "sakai-tasks": {
      "command": "<あなたが解凍したrun.shファイルのパス>",
      "args": []
    }
  }
}

    AI に設定ファイルへの追記を依頼する場合のプロンプト例:

    あなたのMCP設定ファイルに、以下のMCPサーバーを追加してください。
名前: sakai-tasks
コマンド: <あなたが解凍したrun.shファイルのパス>
  4. AI アシスタントを再起動します。
  5. AI のチャット欄で「初期設定を開いて」と指示します。
  6. 設定画面が開いたら、所属大学のドメイン（例: tact.ac.thers.ac.jp や lms.gakusei.kyoto-u.ac.jp 等）を入力または一覧から選択します。設定は自動保存されるため、右上の閉じるボタン（✕）で画面を閉じます。
  7. AI のチャット欄で「直近の課題を教えて」など Sakai に関する質問をすると、ログイン画面が自動で開きます。ログインが完了すると画面が自動で閉じ、AI が情報を回答します。
